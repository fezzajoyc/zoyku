# 六个已有工具的能力与契约对照

研究日期：2026-11-20（Asia/Shanghai）；代码基准：`dccdbfd`；分支：`codex/tool-parity-cn`。

本报告比较明确能力维度，不做总分或全站排名。Zoyku 六页均用 Chrome 157 在本地 `3480` 服务输入真实内容；同行只读取官方页面，**全部未交互实测**。不能据此声称任何工具全面优于同行。完整输入、输出和下载语义证据在同名 JSON 的 `browserEvidence`。

评级口径：**优势**＝具体维度有直接结构/流程证据；**相当**＝列明基础能力均存在，不表示性能/准确率等同；**落后**＝能力覆盖或自身承诺有已证明缺口；**未知**＝无同样本证据。

## 逐工具证据

### `image-compressor`

**限定判断：落后。** 格式/流程覆盖及自身文案兑现度；不代表压缩画质、压缩率或总体产品排名。

官方来源：[P1 TinyPNG 官方首页](https://tinypng.com/)。仅核对页面说明，未交互实测。

本地核对：`tools/image/image-compressor.ts`、`tools/_engines/image-engine-canvas.tsx`、`tools/_engines/image-results.tsx`、`tools/_engines/image-util.ts`。

| 维度 | 判断 | 证据与边界 |
| --- | --- | --- |
| 内容在设备上处理 | 优势 | 本地源码由loadImage/Canvas/toBlob处理；TinyPNG官方页面为上传服务。优势限于免上传流程，不是对任何服务隐私合规性的判断。 |
| 批量压缩流程 | 相当 | 本地2张真实PNG产生2条结果并下载JPEG；同行官方页列批量压缩。双方通用批处理能力存在，未作同样本产物比较。 |
| 格式覆盖 | 落后 | 本地输出选项只有JPG/WebP/PNG；TinyPNG官方标题另外列AVIF和JPEG XL压缩。不能据此断言本地浏览器完全无法解码AVIF。 |
| 同等视觉质量下体积、速度与大图稳定性 | 未知 | 没有将同一组图像提交同行，也未做SSIM/感知质量和设备基准。 |

**已观察的限制／契约差距：**

- dccdbfd英文intro声称可逐文件调节，实际只有一个全局quality状态，浏览器也只见一个滑块；逐文件前后体积读数不等于逐文件设置。
- dccdbfd英文正文将RAW/无体积限制写成通用能力；实际依赖浏览器解码和Canvas资源，未发现RAW专用解码器，不能保证任意RAW或无限尺寸。
- PNG走Canvas无损重编码，源码未见专用PNG量化路径；不能仅看编码方式推定与同行的实际压缩率差异。
- 合成PNG从46766B转JPEG为9061B，是单个样本不同编码的结果，不能外推为优于同行或对所有图片都节省81%。

**后续验收重点：**

- 修正文案或补齐真实逐文件设置；声明解码/内存边界。
- 用照片、透明截图、已压缩JPEG、动画/色彩配置和大像素样本作同画质比较。

### `merge-pdf`

**限定判断：相当。** 基本多文件排序合并能力；未证明复杂PDF兼容性相当。

官方来源：[P2 iLovePDF 官方合并页](https://www.ilovepdf.com/merge_pdf)。仅核对页面说明，未交互实测。

本地核对：`tools/pdf/merge-pdf.ts`、`tools/_engines/pdf-engine-pages.tsx`、`tools/_engines/pdf-ui.tsx`。

| 维度 | 判断 | 证据与边界 |
| --- | --- | --- |
| 免上传处理 | 优势 | 本地pdf-lib在浏览器读取/生成；同行官方合并页明确上传流程。 |
| 基础选择、排序、合并 | 相当 | 本地支持文件拖拽及上/下按钮；实测2份合法PDF调序后下载，解析输出2页宽度为[300,200]；同行官方页列拖拽排序合并。 |
| 书签、交互表单、签名与链接兼容性 | 未知 | 本地正文已提示文档级信息限制，但未用复杂PDF语料与同行逐项验算。 |
| 大文件耗时和内存 | 未知 | 本次是2份简单PDF，不能支持正文中20+文件或100–200MB体验承诺。 |

**已观察的限制／契约差距：**

- 当前路由以文件列表排序；页缩略图逻辑在rearrange分支，不能把它算作merge页已具备的逐页可视化编排。
- copyPages是页面对象复制，不是整个PDF逐字节不变；书签、表单值、文档级结构与数字签名需单独验证。

**后续验收重点：**

- 增加书签、同名表单、内部跳转、加密/损坏、混合页面尺寸和较大扫描件的产物语义检查。
