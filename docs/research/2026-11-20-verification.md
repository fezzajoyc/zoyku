- 新增中国身份证号码校验/解析、规则测试样本生成两个独立工具；注册表由205变为207，支持15种语言。省级前缀与六位形状检查不等于现行/历史县级码或真实身份核验；样本不保证不会与已分配号码重合。输入/结果默认遮盖，本地显示、复制及TXT导出边界明确。

- JSON格式化/压缩改为词法无损：保留数字/转义/重复键/原键序；主动开启时才稳定排序。输入1,000,000、输出4,000,000 UTF-16 code units，200层、100,000值（含容器、不含键）；超限拒绝，无部分输出。15语说明、资源错误、空态/Clear及选中状态同步。
- 修正图片压缩15语能力承诺，明确全局设置、浏览器编解码/内存边界、PNG画质与可能变大的结果；补格式/缩放单位的可访问选中状态。
