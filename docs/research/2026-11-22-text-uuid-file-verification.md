# 文本筛选、UUID 与原始文件：集成验收

日期：2026-11-22（Asia/Shanghai）。本批继续实施 420 行完整对照中已确认、无需外部服务的缺口。新增三条路由，当前为 **222 个工具 × 15 语 = 3,330 个工具页，48 个 MCP 工具**。本工作单元没有执行推送或部署。

## 交付范围

- **text-line-filter**：字面包含/排除、含首尾的一基行范围、Unicode 码点长度、字面分隔列提取。区分无匹配、一个空行和完全空输入；可选列缺失报错或空字段。10 万输入/20 万输出 UTF-16、1 万行；不实现正则和 CSV 引号解析，01-026 保留部分覆盖。
- **uuid-validator-converter**：UUID 标准文本、HEX、128 位二进制和严格带填充 Base64 互转，输出大小写、URN、花括号和字节。按 RFC 9562 区分版本、变体、NIL/MAX 和未识别布局，格式解析成功不证明随机性、唯一性或生成算法。输入上限 128 UTF-16 单元。
- **file-splitter-merger**：按字节大小或均衡份数拆分本地文件，按可重排的用户顺序合并原始字节并下载。使用 Blob.slice/Blob 拼接，避免先把整组文件复制到 JS 数组。总计 50 MiB、最多 100 文件/片；空文件只生成一空片。文本语义、PDF 页和档案解析另保留缺口。

三者原生页面和运行时文案均覆盖 15 语，注册表派生目录、SEO 和 Markdown 页面。MCP 复用相同纯函数；文件接口只返回切分计划，不接收文件内容。
