# 主站自我审查：数据保值与错误恢复

日期：2026-11-21（Asia/Shanghai）。基线 `138735e`，分支 `codex/self-review-recovery`。当前仍为 **209 个工具**、15 种语言；本批修复既有能力，不新增工具入口。未推送、未部署。

## 实际发现与修复

| 范围 | 原始故障与修复 | 保留边界 |
| --- | --- | --- |
| JWT 解码 | `null` 负载访问 `exp`、`1e100` 时间格式化会使整页崩溃。现先验证两/三段 Base64URL、严格 UTF-8、头部/负载对象及顶层键唯一性；错误保留输入并可继续编辑。复用无损 JSON 树显示、复制大数、溢出/下溢数值原文。 | 仅查看明文 JSON，不验签、不验证签发方/受众/授权，不支持五段式加密 JWE；两段输入仅作为查看便利。 |
| JWT 时间注释 | 原先把未验签令牌标“有效”，且 `exp === now` 未判过期。现仅标“未过期/已过期（解码时）”，在输入事件捕获设备时钟，比较 `exp <= now`，不在渲染中读取时钟。高精度数值若经 Number 改变十进制值，拒绝时间注释而保留 JSON。 | 时间显示不是信任判定，不实时倒计时；超出数值精度/日期支持时有15语说明。总输入1,000,000 UTF-16代码单元；每JSON块深度200、值100,000、输出4,000,000代码单元。 |
| JSON/CSV 双向转换 | 所选分号/Tab 没有正确引号转义；`9007199254740993` 被舍入、`1e309` 变 null。现使用所选分隔符转义；JSON→CSV 保留数字原文并拒绝重复键；CSV→JSON 仅作可安全序列化的保守推断。补齐单列空记录、BOM引号表头、引号闭合、等宽行、重名表头检查。 | CSV没有类型系统。缺失值/null输出空格位；空字符串/数值字符串/布尔字符串等不能普遍恢复原JSON类型。前导零、不安全整数、负零、溢出/下溢及会丢十进制精度的值保留为字符串；不保证下游表格软件不自动转换。 |
| CSV 资源限制 | 短CSV的长表头重复后可能放大成巨量JSON；原先先整体stringify再测限额。现先精确预算含转义、缩进和重复表头的UTF-16长度，超限提前拒绝，再逐行序列化；4,000,000与4,000,001边界已测。 | 输入1,000,000、输出4,000,000代码单元；JSON输入还受深度200、值100,000限制。不截断结果；CSV/JSON输入输出固定LTR，外围标签仍按语言排版。 |
| URL 解析 | `example.com:8080/path?x=1` 被识别成 `example.com` 协议，主机为空；路径 `.filter(Boolean)` 丢掉内部/尾部空段。现提取纯函数，按公开的保守规则区分主机端口和自定义scheme，保留空段、重复query、`+/%2B`语义。 | 显式 `scheme://` 优先；点分主机/localhost+数字或空端口按HTTPS，其它冒号前缀保留自定义scheme。歧义需用户写明协议；IPv6需方括号。仍使用浏览器URL规范化，不是原字节解析器。 |
| 共享复制按钮 | Clipboard拒绝且fallback为false仍报“Copied”；fallback抛错会冒泡；旧异步结果/定时器可覆盖新输入或更新的点击。现只在确实成功时反馈，始终清理临时textarea/恢复焦点，源/回调变化和卸载使旧操作失效。 | 保留单button根DOM、原class和回调接口。15语失败短标签可见，完整恢复说明通过title和无障碍description提供；不新增依赖或产品路由。 |
| 身份证复制/TXT | 原异步提示会在编辑、清空、重跑、显示/遮盖后回流；交叉审查又复现新复制/下载被旧复制覆盖。现各操作推进revision，复制开始清除旧提示；下载异常可恢复，已创建URL在点击前安排回收。 | 原身份真实性、行政区划数据与测试样本边界不变；不能把结构/校验位通过当成真实身份核验。 |
| 图标契约 | 注册项用了不存在的 `calculator`、`diff`；`constructor/toString/__proto__`可命中继承属性并在`.split`崩溃。现注册项用实际glyph，查找仅接受own property；其余安全回退。 | 人民币用calc、PDF比较用pdf；未重设计图标系统。 |

## 证据与交叉复审

- JWT 原界面12项回归先全红，纯函数和UI现62项；交叉审查的 `1000.00000000000001`、`8640000000000.0001` 两项再现舍入后先红再绿。最后核对发现界面空白判断早于原始输入限额，超限空格可绕过检查；再加一项先红后绿，限额现于空态判断前执行，原输入不截断。标准依据实际读取 RFC 7519 官方正文：Claims Set为JSON对象，NumericDate为秒且可带小数，exp处理时要求当前时间早于exp。此处是查看工具的保守支持策略，不是完整JWT验证器实现。来源：<https://www.rfc-editor.org/rfc/rfc7519.html>，文本快照保存在外部证据目录。
- 共享复制浏览器由6/36通过变为36/36，17项SSR/文案测试；临时fixture挂载真实组件，仅对Clipboard/DOM外部API注入失败。34项fixture和2项实际工具集成分别留证，不把fixture说成整站生产验收。64个调用点和4类自定义class已检查，Clear高度/按钮矩形未被wrapper改变。
- CSV旧实现15项回归全红后全绿；新增资源预算、空记录/BOM问题均先红再绿。CSV新增176项测试；连同现有JSON与transforms共412项。实际剪贴板CSV/TSV另用Python标准库严格解析核对。HTML textarea会规范化CRLF为LF，报告区分DOM值与实际剪贴板产物，不承诺浏览器文本框字节往返。
- 图标测试验证209个注册键和未知/继承属性回退；先缺helper、再注册表、再旧查找崩溃，保留逐步红证据。
- 身份证原84检查保留，新增16个重叠/待定通知场景归入4个检查，共88检查。开发态最终曾87/88，一次日语校验页提交后没有结果区，亦曾在德语生成准备中超时，无pageerror；没有确认根因，HMR相关性仅是假说。没有通过加sleep/重试掩盖；脚本补了表单、导航和HMR诊断。生产新上下文另核，结果见下。
- JWT开发态初次axe有3个主题切换中间帧对比度失败；实测发现150ms颜色transition未结束。等待实际前/背景色到达目标主题后8态0违规、0incomplete；未为测试改CSS，也不把中间帧当最终主题结果。
