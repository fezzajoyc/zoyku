# CSV 表格与整图色板

用户已授权连续补齐有证据的同行缺口，并在本轮明确允许更多代理。两项对应公开目录来源见研究批次 3。本轮在当前工作树交付两个独立工具，保留已有改动。核心计算、原生 15 语页面、注册表派生 SEO、MCP 和浏览器验收一起完成。

CSV 编辑器提供矩形表格转置和一基列号互换，首行与其他行按同样规则处理。复用严格 CSV 解析器，不推断数字或修改空格。支持逗号、分号和 Tab；错误时清空结果并说明原因。输入 100 万、输出 400 万 UTF-16 单元；10 万单元格、1 万行和 1,000 列为硬限制，转置后的形状也受限。

整图色板先按每 RGB 通道五位分组，再按 alpha 加权计数和组内原始颜色均值排序。最多按均匀位置采样 65,536 像素，默认显示前八组，可选 1–12 组。完全透明像素不计入颜色占比。占比以全部可见样本权重为分母，选中的组不一定合计 100%。这是一组常见颜色的近似统计。网页明确图像尺寸、样本数和限制，处理本地文件。

网页使用共享 CopyButton 和主题变量，文本关联真实标签，RTL 里地址和数据文本保持 LTR。MCP 分别使用同一纯函数处理 CSV 字符串和小尺寸原始 RGBA 数组；后者不提供图像文件解码。

验证包括独立固定向量、失败边界、数量和资源上限、协议调用、15 语契约、生成 HTML 与真实 HTTP、320/390px 和键盘复制。浏览器用合成样本而非用户资料。全仓测试与构建通过后记录范围，研究矩阵单独保存来源和未测项。
